# Savoria — Restaurant & Food Ordering Website

A polished, responsive restaurant website concept designed to give a neighborhood restaurant a warm, modern online presence. Savoria combines editorial typography, fresh food photography, a curated menu, and simple ordering interactions in a clean one-page experience.

## Preview

**Live demo:** Enable GitHub Pages for this repository to publish the website.

## Features

- Responsive layout for desktop, tablet, and mobile screens
- Modern restaurant branding and welcoming hero section
- Menu cards with category filters
- Add-to-order interactions with item count and running total
- Order summary preview
- Restaurant story, guest review, contact details, and footer
- Contact form with front-end validation and demo feedback
- Mobile navigation and smooth section scrolling
- SEO-friendly page title and meta description

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Lucide Icons
- Unsplash image URLs

## Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No build tools or package installation are required.

## Customize the Website

Replace the sample restaurant name, menu items, prices, address, phone number, opening hours, and review with your own business information. Update the image URLs to use your preferred food and restaurant photography. Connect the order and contact interactions to a real backend or ordering service before accepting customer orders.

## Important Demo Notice

This is a front-end portfolio demonstration. The order preview does not place or transmit an order, and the contact form does not send or store messages. Sample restaurant details and prices are illustrative. Do not use it to collect real customer or payment information without implementing a secure backend and appropriate privacy practices.
